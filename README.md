# Информационная система учета пациентов и медицинских услуг ветеринарной клиники (Veterinary Clinic Management System)

## Концепция системы
Система предназначена для автоматизации процессов управления ветеринарной клиникой. Она позволяет вести учет пациентов (животных) и их владельцев, контролировать распределение приемов между врачами, планировать вакцинацию и лечение, отслеживать истории болезней, а также управлять складом медикаментов.

### Основные модули:
- **Учет пациентов:** Карточки животных (вид, порода, возраст, вес), привязка к владельцу.
- **Управление приемами:** Расписание врачей, онлайн-запись, бронирование времени.
- **Медицинские услуги:** Каталог услуг, прайс-лист, назначение процедур.
- **Аналитика и отчеты:** Выручка клиники, загруженность врачей, статистика по заболеваниям.

## Технологический стек
- **Backend:** Node.js, Express.js (REST API, высокая производительность).
- **Frontend:** TypeScript, React, TailwindCSS (адаптивный интерфейс для администраторов и врачей).
- **СУБД:** PostgreSQL (хранение реляционных данных о пациентах и приемах).
- **Контейнеризация:** Docker, Docker Compose.
